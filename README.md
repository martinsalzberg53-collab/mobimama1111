# Mobi Mama – Maternal Health Support Platform

Mobi Mama is a digital maternal-health application designed to support mothers with easy access to clinics, nurses, pregnancy tips, and intelligent health guidance.  
The project uses **Django (backend)** and **React (frontend)** to deliver a modern, fast, and reliable experience.

---

## 🌸 Overview

Mobi Mama helps expecting and new mothers stay informed, connected, and supported.  
It offers appointment booking, curated tips, and AI-driven assistance all in one platform.

---

## 🎯 Core Features

### 1. Tips System
- Daily and weekly pregnancy tips  
- Categories: Pregnancy, Nutrition, Baby Care  
- Personalized recommendations based on pregnancy stage  
- Tips created and managed by Admin/Nurse users  

### 2. Appointment Booking System
- Mothers can book clinic appointments  
- Nurses can approve, decline, or manage bookings  
- Appointment statuses: `pending`, `approved`, `completed`  
- Optional reminders via email/notifications  

### 3. AI Support System
- AI chat assistant for common pregnancy/baby care questions  
- Smart weekly tip recommendations  
- (Future) Non-diagnostic symptom checker  

### 4. Profiles & Dashboards
- Mother Profile  
- Nurse Profile  
- Admin dashboard overview of users, clinics, and appointments  

---

## 🏗️ Tech Stack

### Backend (Django)
- Django REST Framework  
- PostgreSQL or SQLite  
- (Future) Celery for reminders and async tasks  

### Frontend (React)
- React + Vite  
- Axios for API requests  
- React Router  
- Context API / Redux (optional future addition)
